# 京东带货视频提示词与制作策略

状态：实验策略，基于本项目实际生成记录持续修订。
更新日期：2026-10-26

## 目标

制作能清楚介绍真实商品、具有观看价值的短视频。先保证商品一致性、表达准确和视听质量，再考虑生成效率。目标不是让模型执行最长的提示词，也不是把所有物体冻结成15秒静态广告图。

当前暂停反复换品试生成，先建立可比较、可验收的实验流程。本文不改变应用代码，不代表平台审核通过保证。

## 研究定位：可控视频生成

领域名称：**Controllable Video Generation（可控视频生成）**。

本项目的具体研究主题：**Controllable Product Video Generation with Identity Preservation（保持商品身份一致性的可控视频生成）**。

这里的商品身份一致性（product identity preservation）是指：跨帧、跨镜头仍能核对为同一品牌、同一款式的商品，保留其关键轮廓、颜色、纹理与结构；仅生成一个相似物体并不足够。它不要求不同视角下的像素完全相同。

| 控制维度 | 本项目中的含义 | 检查重点 |
| --- | --- | --- |
| 外观控制（Appearance Control） | 按真实商品参考生成外观 | 款式、颜色、关键结构与SKU匹配 |
| 运动控制（Motion Control） | 指定物体动作、轨迹与摆放变化 | 动作合理，无穿模、漂移和物体增减 |
| 镜头控制（Camera Control） | 指定视角、运镜及镜头切换 | 指令遵循、空间关系和剪辑可理解性 |
| 时序一致性（Temporal Consistency） | 随时间保持主体身份及结构稳定 | 无非预期的形变、纹理闪烁或身份漂移 |

研究问题：**如何在商品图驱动的视频生成中，同时保持商品真实性与内容表现力？**

英文表述：*How can reference-image-guided product video generation preserve product identity while enabling expressive motion and camera control?*

当前工作属于生成式视觉系统的应用实验。若要形成可复现研究，应固定商品、参考素材、模型及基础参数，每次改变一个控制条件，并记录商品一致性、时序一致性、指令遵循和内容价值。听检与平台发布验收仍是独立的必要环节。提示词是控制手段之一，也应比较参考图条件、工具实际支持的结构化控制及后期制作方式。

此处是项目研究方向命名，不是对用户正式博士学位或专业名称的认定。

## 已观察到的问题

| 案例 | 实际观察 | 对策略的启发 |
| --- | --- | --- |
| 鞋架第一版 | 鞋架和鞋子出现，额外金属杆、鞋子变化 | 不在同一生成片段内要求空场景变成整理后场景 |
| 鞋架第二版 | 约7–8秒新增白鞋 | “数量不变”文字约束没有可靠锁定物体 |
| 鞋架第三版 | 约3秒新增第二个架子，场景未遵守单柜格要求 | 继续堆叠禁止事项没有解决参考画面的歧义 |
| 镂空收纳篮 | 前段较稳定，约8秒后轮廓和把手变化 | 密集重复孔洞、角度变化增加一致性检查难度 |
| 玻璃鼠标垫 | 逐秒抽帧未见明显物体增减或大幅变形，但内容单薄，鼠标在垫外 | 稳定是必要条件，静止不等于优质介绍 |
| MUJI靠垫 | 镜头切换后朝向、摆放变化 | 需要区分正常剪辑与连续镜头中的无原因跳变，不能仅凭切镜后朝向不同判失败 |

以上为视觉抽帧观察，不等于完整逐帧审查。此前各片的旁白均未完成听检，不能据此判定成片整体合格。靠垫朝向变化应结合切点和完整播放复核；此前直接认定不通过的结论偏严格。

## 关键判断

1. 提示词是引导，不能保证商品外观逐项一致。“严格1:1”“绝不变形”不能替代验收。
2. 原商品图、生成首帧、生成视频是三次检查：生成首帧本身也可能改错产品。
3. 宣称“使用首帧”不等于工具已将图片绑定到首帧槽。必须核实附件和页面实际模式；若仅为对话引用，应记录为参考图条件。
4. 电商拼图包含多个产品、角度、文字和示意，容易造成歧义。优先用有权使用的单商品清晰图，并保留原始来源。
5. 复杂度由产品、场景和动作共同决定。不能只按产品外形判断，也不能因一次失败就换品。
6. 场景稳定、商品介绍具体、旁白有信息量需要同时满足。空泛的“核对尺寸”不能成为所有商品的万能脚本。

## 工作流程

### 1. 建立商品事实卡

生成前记录：SKU、链接、品牌、当前选中款式/颜色/尺寸、数量、可验证卖点、参考图来源及使用授权、不可宣称的内容、挂链可用性。

区分商品页明确资料、用户评论、个人体验和推断。评论不是我们的实测证据。价格和佣金是动态信息，默认不写进口播。

### 2. 先确定内容价值

每条视频只解决一个具体问题，例如“这款靠垫的形状如何搭配阅读角”。选2–3个有商品资料支持的信息点，说明画面如何证明或呈现它们。

没有实物与测试证据时，不做触感、回弹、承重、耐久、治疗或游戏性能的实测表述。AI画面不能证明这些性能。

### 3. 决定制作方式

| 画面任务 | 优先方式 |
| --- | --- |
| 品牌、外观、尺寸、细密结构必须准确 | 有权使用的真实商品图/视频，靠剪辑和构图呈现 |
| 家居氛围、阅读角、背景空镜 | 可用AI生成，核查背景是否误导商品用途 |
| 简单商品的短时外观展示 | 先做单片段图生视频实验，验证一致性 |
| 安装、承重、回弹、真实使用效果 | 实拍或获授权且真实匹配的演示素材 |

优先考虑混合制作：真实商品素材负责准确展示，AI负责适合的场景，剪辑负责节奏，旁白负责解释。避免简单图片拼接，确保镜头各自提供信息。合成时也不得改变商品比例、结构或造成误导。

### 4. 先测试一个短镜头

先测试工具支持的短片段（例如4–5秒，具体以界面为准），只设一个主体、一个动作或一种镜头运动。检查合格后再扩展完整视频。

不要同时要求模型生成复杂场景、三次切镜、物体交互、产品结构演示和长口播。完整15秒可由多个独立验收的镜头剪成，前提是剪辑有内容逻辑而非凑时长。

### 5. 单变量迭代

同一SKU、同一参考图、同一模型下，每次只改一项：动作、运镜、时长或提示词。记录预期与实际差异。

同一问题连续两次仍存在，改变制作方式或参考条件，避免仅增加禁止词。该阈值是本项目节省额度的工作约定，不是平台规则。

### 6. 成片验收再预览

下载原文件并完整播放，记录具体时间点。抽帧用于快速发现问题，不能代替运动连续性和音频检查。

## 提示词结构

按以下顺序写，保持简短、具体、一致：

1. 任务和交付：一个短镜头，比例、时长。
2. 商品身份：附件编号、SKU/款式、3–5个可见的外观要点。
3. 起始状态：产品在哪里、已经摆了什么、背景是什么。
4. 唯一运动：产品不动，镜头缓慢推近；或固定机位下的一个可执行动作，二者不要互相冲突。
5. 外观与光线：保持真实色彩和可见材质，不写无法兑现的“8K原生RAW实拍”。
6. 少量针对性限制：只写本镜头最容易犯错的2–3项。
7. 音频：如需生成旁白，明确短台词；后期独立配音通常更便于修正和计时。

不在生成提示词中夹入审核流程、法律承诺、平台收益、长篇失败历史或“无需再确认”等无关内容。工具若要求参数确认，应单独完成。

```text
[无旁白，后期配音 / 一句明确旁白]。
```

## 验收标准

| 项目 | 通过条件 | 不通过例子 |
| --- | --- | --- |
| 商品匹配 | 品牌、款式、颜色、结构与SKU可核对 | 错颜色、改轮廓、凭空增加零件 |
| 时间连续性 | 同一镜头的物体运动合理 | 无原因出现/消失、穿模、漂移 |
| 剪辑 | 切点明确，主体及空间关系能理解 | 混合不同款式、叠影残像；正常换角度本身不是错误 |
| 内容价值 | 每个镜头呈现具体信息，旁白与商品有关 | 只延长静态画面、通篇空泛话术 |
| 音频 | 完整听检，吐字清楚，无截断，音乐不遮盖人声 | 仅检查“存在音轨”就认为通过 |
| 真实性 | AI演示与真实体验区分，声明准确 | 冒充实拍、无依据的性能承诺 |
| 技术 | 上传页要求的格式、时长和分辨率均核实 | 只相信生成器文字描述 |

验收结论用“通过 / 需修改 / 待核查”，写明证据和未完成检查。不得从抽帧稳定直接推导平台会通过，也不因轻微构图差异一概判失败。
