## 停止 Tauri 并回退的条件

M0 最多投入计划中的 3–5 个工作日。遇到下列任一阻断，记录复现步骤与修复尝试后评估 Electron：

1. 豆包或京东关键登录、生成、上传路径在 WKWebView 中无法正常执行，且稳定支持的方案无法解决。
2. 不同账号会话互相污染，或退出应用后无法可靠恢复；不能用共享会话伪装多账号。
3. 关键功能必须长期依赖不稳定 API、不可维护的私有实现或侵入式补丁。
4. 下载或平台交互无法满足可观察、可恢复的最低要求。

单纯包体大小、界面样式或一次网络超时不作为回退理由。尚未有账号登录验证时标为“未验证”，不能宣称通过或失败。

## 回退执行步骤

1. 保存 Tauri 代码、复现记录及当前依赖锁文件，用提交或标签建立检查点。
2. 保留 React 管理界面和领域数据接口，将桌面桥接替换为受限 Electron preload IPC。
3. 使用每账号独立持久 session partition，实现对应的平台窗口与下载记录。
4. 通过同一组隔离、恢复、真实生成下载与上传检查，再决定最终技术栈。
5. 迁移非敏感业务数据；WebKit 会话默认不迁移，要求重新登录。

两种运行时的用户数据目录保持独立，不以不可逆迁移作为试用前提。当前数据库覆盖范围见下方各轮记录，完整任务与素材数据层尚未实现。
